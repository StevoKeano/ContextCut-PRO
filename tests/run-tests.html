📡 MCP Knowledge Server

mcp_knowledge_server.py exposes ContextCut-PRO's knowledge base and file ingestion pipeline via the Model Context Protocol — usable by Claude Desktop, Cursor, VS Code Copilot, ChatGPT, Gemini, and any MCP client.

Run the server

# stdio transport (for local agents like Claude Desktop)
python mcp_knowledge_server.py

# HTTP transport (for remote agents)
python mcp_knowledge_server.py --transport http --port 8910

Available tools

ToolParametersReturns
knowledge_search query: str, top_k: int = 5 Formatted text with sources and scores
knowledge_search_structured query: str, top_k: int = 5 list[{source, score, text}]
knowledge_list_files none list[{name, path, size, modified}]
knowledge_stats none {total_chunks, total_files, embed_mode, proxy_requests, ...}
ingest_file filename: str Status string ("Ingested doc.md: 5 chunk(s)")
ingest_all none Multi-line status
ingest_status none list[{name, current}]

Resources (read-only data)

URIReturns
knowledge://filesJSON list of files
knowledge://statsJSON stats dict
knowledge://search/{query}JSON structured search results

Client configuration

{
  "mcpServers": {
    "contextcut-knowledge": {
      "command": "python",
      "args": ["/path/to/mcp_knowledge_server.py"],
      "env": {
        "CONTEXTCUT_QDRANT_HOST": "localhost",
        "CONTEXTCUT_QDRANT_PORT": "6333",
        "CONTEXTCUT_COLLECTION": "contextcut",
        "CONTEXTCUT_KB_DIR": "/home/user/contextcut/knowledge",
        "CONTEXTCUT_EMBED_MODE": "ollama",
        "CONTEXTCUT_EMBED_MODEL": "nomic-embed-text",
        "CONTEXTCUT_UPSTREAM": "http://localhost:11434"
      }
    }
  }
}
Cursor — Settings → MCP Servers → Add → same JSON (omit mcpServers wrapper).
VS Code Copilot — .vscode/mcp.json → same format.

python -m pytest tests/test_mcp_server.py -v --tb=short

  ChatGPT/etc.)                             │
        │                                    ├── knowledge_search ──► qdrant_context()
        │                                    ├── ingest_file ──────► _batch_embed() + QdrantClient
        │                                    ├── knowledge_stats ──► make_stats_json() + QdrantClient
        │                                    ├── knowledge://* ────► resource endpoints
        │                                    │
        │                                    ├── depends on qdrant_proxy_final (lazy clients)
        │                                    └── embeds via Voyage AI or Ollama

        ┌────────────────────────────────────┴───────────────────────┐
