# Document Review and Analysis Framework

## Risk Assessment Scale
| Level | Description | Action |
|-------|-------------|--------|
| Critical | Invalidates core purpose | Must revise |
| High | Creates material liability | Strongly recommend revision |
| Medium | Non-standard but acceptable | Flag to client |
| Low | Preference difference | Note only |
| Informational | No material impact | No action |

## Common Red Flags
*(Add red flags specific to your profession)*
- Ambiguous terms without definition
- Missing standard provisions (termination, dispute resolution, etc.)
- One-sided allocation of risk
- Auto-renewal without adequate notice
- Unlimited liability or indemnification

## Review Methodology
1. **Purpose Check** — Does the document achieve the goal?
2. **Risk Scan** — Identify high-risk provisions
3. **Gap Analysis** — Missing necessary terms
4. **Consistency Check** — Internal conflicts between provisions
5. **Authority Check** — Compliance with applicable rules

## ContextCut Prompts
- "Identify all one-sided provisions in this [document type]"
- "Compare these [clause type] options and recommend the best approach"
- "Flag any provisions inconsistent with [statute/regulation/standard]"
