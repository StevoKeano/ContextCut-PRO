# Communication Templates

## Communication Principles
- Know your audience (sophistication level, familiarity with subject)
- Lead with the answer, then explain reasoning
- Use plain language for clients; technical precision for peers
- Set clear expectations on timelines and next steps

## Tone Guide
| Situation | Recommended Tone |
|-----------|-----------------|
| Complex or sensitive matter | Patient, explanatory |
| Time-sensitive issue | Direct, action-oriented |
| Routine update | Reassuring, concise |
| Formal filing | Precise, thorough |
| Negative outcome | Empathetic, solution-oriented |
